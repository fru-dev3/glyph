Getting started

Install Glyph, reload zsh, then verify without launching an agent.

git clone https://github.com/fru-dev3/glyph.git
cd glyph && ./install.sh && exec zsh
GLYPH_DRYRUN=1 claude checkout-fix

The installer copies the wrapper to ~/.config/glyph/ and updates ~/.zshrc.

Session list

This lists names Glyph has recorded. It does not open a workspace.

Manage Fleet

These commands manage saved groups of agents. Fleet uses whichever workspace harness you choose below.

Create the example fleets

glyph fleet init

Writes twelve starting presets to ~/.config/glyph/fleet.conf without touching definitions you already have. Run it again any time; it only adds what is missing.

A slot is <agent> or <agent>:<machine>. Replace studio with one of your own machines — see UpdatingRemote agents.

Preview, then open

GLYPH_DRYRUN=1 glyph fleet ci
glyph fleet ci

The default ci group contains Claude Code, AGY, and Codex. Fleet is the only layer that opens multiple agents.

Updating

Glyph is one file. Pull the latest straight from GitHub:

glyph update
exec zsh
glyph version

It downloads glyph.zsh, refuses to install anything that does not parse, keeps your previous copy at ~/.config/glyph/glyph.zsh.bak, and leaves your fleet.conf, names.tsv and agents.tsv untouched. Point GLYPH_UPDATE_URL elsewhere to track a fork.

Remote agents

Any slot can name a machine. Glyph opens an SSH session in that pane, changes to the same working directory, and launches the agent through the remote Glyph wrapper so it gets that agent's own flags and its own mark.

glyph hosts
glyph fleet split          # claude here, codex on the remote box
GLYPH_DRYRUN=1 glyph fleet cloud

How a machine name is resolved

Glyph tries these in order, and stops at the first hit:

1 · SSH configHost mini

An entry in ~/.ssh/config always wins.

2 · known_hostsmini

A name SSH already trusts, so the pane never stalls on a fingerprint prompt.

3 · Tailscalemini → mini.tailnet.ts.net

Short machine names are matched against your tailnet and expanded to MagicDNS.

4 · Literaluser@10.0.0.5

Anything else is passed to SSH untouched.

Run glyph hosts to list every machine you can put after the colon: your SSH config entries, plus tailnet machines with their online status. Tailscale is optional and detected automatically; nothing changes if you do not use it.

First connectionssh miniAccept the host key once by hand. After that, remote panes start clean.

Remote slots work on every backend — Herdr, tmux, cmux, Zellij and WezTerm — because they all build the same SSH command. Glyph is not tied to any one workspace tool; with no workspace running, Fleet falls back to tmux.

Adapters

Glyph keeps the command you already know and adds the same readable session name around it. A wrapper is defined only for agents actually on your PATH.

Adding an agent yourself

Any CLI can be wired up without waiting for a release. One tab-separated line per agent in ~/.config/glyph/agents.tsv:

openclaw	--yolo	OpenClaw
grok	--force	Grok

Columns are command, auto-approve flag, label. Leave the flag empty if the agent has none. These merge over the built-ins, so you can also correct a flag Glyph gets wrong.

Naming

Glyph builds one lowercase, hyphenated mark from label, project, agent, machine, and start time.

checkout-fix·acme-api·claude-code·studio·2026-09-12·0912

Machine identity comes from ComputerName or hostname. Override it with GLYPH_MACHINE. Project aliases live in ~/.config/glyph/names.tsv.

Configuration

GLYPH_OFF=1Omit machine and time.
GLYPH_TITLE=0Leave terminal titles unchanged.
GLYPH_LOG=0Skip the local session log.
GLYPH_YOLO=1Enable auto-approve.
GLYPH_DRYRUN=1Print instead of launch.
GLYPH_FLEET_CONFUse another Fleet config path.

Workspace harnesses

Harnesses decide where Fleet opens. They do not change how you launch a single agent.

HerdrGLYPH_FLEET_BACKEND=herdr glyph fleet ci

One Herdr tab per local agent.

cmuxGLYPH_FLEET_BACKEND=cmux glyph fleet ci

One cmux workspace per local agent.

ZellijGLYPH_FLEET_BACKEND=zellij glyph fleet ci

One named Zellij pane per local agent.

WezTermGLYPH_FLEET_BACKEND=wezterm glyph fleet ci

One WezTerm tab per local agent.

tmuxGLYPH_FLEET_BACKEND=tmux glyph fleet ci

Tiled panes; supports SSH slots.

AutomaticGLYPH_FLEET_BACKEND=auto glyph fleet ci

Detects Herdr or cmux, then uses tmux.
