Glyph docs.

Installation, commands, Fleet, adapters, naming, and configuration in one reference.

Getting started

Install Glyph, reload zsh, then verify without launching an agent.

git clone https://github.com/fru-dev3/glyph.git
cd glyph && ./install.sh && exec zsh
GLYPH_DRYRUN=1 claude checkout-fix

The installer copies the wrapper to ~/.config/glyph/ and updates ~/.zshrc.

Launch agents

These commands start one agent through Glyph. The agent command stays familiar; Glyph adds the session name before launch.

Claude Codeclaude checkout-fix
Codexcodex review
AGYagy docs
Preview insteadGLYPH_DRYRUN=1 claude checkout-fix

Session list

glyph ls

This lists names Glyph has recorded. It does not open a workspace.

Manage Fleet

These commands manage saved groups of agents. Fleet uses whichever workspace harness you choose below.

Create the example fleets

glyph fleet init

Preview, then open

GLYPH_DRYRUN=1 glyph fleet ci
glyph fleet ci

The default ci group contains Claude Code, AGY, and Codex. Fleet is the only layer that opens multiple agents.

Naming

Glyph builds one lowercase, hyphenated mark from label, project, agent, machine, and start time.

checkout-fix·acme-api·claude-code·studio·2026-09-12·0912

Machine identity comes from ComputerName or hostname. Override it with GLYPH_MACHINE. Project aliases live in ~/.config/glyph/names.tsv.

Configuration

GLYPH_OFF=1Omit machine and time.
GLYPH_TITLE=0Leave terminal titles unchanged.
GLYPH_LOG=0Skip the local session log.
GLYPH_YOLO=1Enable auto-approve.
GLYPH_DRYRUN=1Print instead of launch.
GLYPH_FLEET_CONFUse another Fleet config path.

Workspace harnesses

Harnesses decide where Fleet opens. They do not change how you launch a single agent.

HerdrGLYPH_FLEET_BACKEND=herdr glyph fleet ci

One Herdr tab per local agent.

cmuxGLYPH_FLEET_BACKEND=cmux glyph fleet ci

One cmux workspace per local agent.

ZellijGLYPH_FLEET_BACKEND=zellij glyph fleet ci

One named Zellij pane per local agent.

WezTermGLYPH_FLEET_BACKEND=wezterm glyph fleet ci

One WezTerm tab per local agent.

tmuxGLYPH_FLEET_BACKEND=tmux glyph fleet ci

Tiled panes; supports SSH slots.

AutomaticGLYPH_FLEET_BACKEND=auto glyph fleet ci

Detects Herdr or cmux, then uses tmux.
