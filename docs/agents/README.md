# Agent logos

PNG assets exported at 128 pixels from the installed apps on 2026-09-12:

- `codex.png`: Codex.app, Contents/Resources/icon.icns
- `agi.png`: Antigravity.app, Contents/Resources/icon.icns
- `claude.png`: Claude.app, Contents/Resources/electron.icns

These are the apps' original icons, not redrawn approximations. AGI is the
website display label requested by Fru; the demo retains the `agy` CLI command.

Additional assets:

- `cursor.png`: installed Cursor.app, Contents/Resources/Cursor.icns.
- `crush.png`: https://github.com/charmbracelet/crush/blob/main/internal/ui/notification/crush-icon-solo.png (resized to 128 px).
- `gemini.svg`, `opencode.svg`, `pi.svg`, `cortex.svg`: https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons (geminicli-color, opencode, pi, snowflake-color). Cortex uses Snowflake's mark.
