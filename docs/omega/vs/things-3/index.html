Glyph Omega vs Things 3

Things 3 is a one-time-purchase task manager for Apple devices, with Areas and Projects and a local database that syncs through Things Cloud. Glyph Omega adds mission, values, goals and a weekly review, and keeps everything as plain files in your vault.

The short version

  • Things is a paid app per device. Omega is free.
  • Things has Areas and Projects. Omega adds goals and a weekly review.
  • Things stores a database file. Omega stores plain files you can read in any editor.

Pick Things 3 if you want a polished task list on Mac, iPhone, iPad, Apple Watch and Vision Pro, paid once, with no subscription.

When to pick Glyph Omega

You want goals broken down to the next action, kept in files you own.
