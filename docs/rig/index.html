Questions

Is Glyph Rig free?

Yes, free and open source under the MIT license.

Which agents does it run?

Claude Code, Codex, AGY, Cursor, Crush, Cortex, OpenCode and pi, and any other command-line agent you add in one line.

Does it phone home?

No network requests except glyph update, glyph usage --live and the GitHub star you agree to.

Where does it work?

In zsh, with tmux, Herdr, Zellij, WezTerm or a bare shell.

How do I install it?

Clone the repo and source install.sh: one file into ~/.config/glyph and one line into ~/.zshrc. glyph update fetches the latest.

What was it called before?

Glyph Code, until October 2026. Same tool and same glyph command.

Everything Glyph Rig does

Where your agents run

A harness, like Claude Code, Codex, Gemini or Cursor, runs AI models. Glyph Rig runs your harnesses: it names every session, connects them across your Macs, launches them and runs them together.

Bot and the Rig

Glyph Bot builds and runs a harness; the Rig connects and manages the harnesses across machines.

Fleets

One preset opens several harnesses at once, each in its own pane: glyph fleet review puts two vendors on the same diff. Slots can run on another machine over SSH.

Every session named

So the Rig knows which is which and where it runs. Keep typing claude, codex or agy. One bare word is your label; Glyph Rig builds the session name and hands it to the agent before the first token. Anything with a space is still your prompt.

Six tokens

Label, project, agent, machine, date and time, lowercase and joined by a dot: billing·acme-api·claude-code·laptop·0556.

Every agent

Claude Code, Codex, AGY, Cursor, Crush, Cortex, OpenCode and pi, and any other CLI you add in one line.

Every machine

The machine is part of the name, so a pane on your laptop never reads the same as one running over SSH.

On your phone

Claude sessions carry the name through Remote Control, so the list on claude.ai/code and the app reads the same as your terminal.

Usage and wake

glyph usage shows quota and token counts across agents. glyph wake continues Claude sessions a usage limit stopped, when the limit resets.

Spaces

Write down once which workspaces and tabs a machine opens and which agent runs in each; glyph spaces rebuilds them in Herdr after a restart.

Works where you work

zsh, with tmux, Herdr, Zellij, WezTerm or a bare shell. There is a Herdr plugin too.

Install and update

git clone https://github.com/fru-dev3/glyph.git && cd glyph && source ./install.sh. One file into ~/.config/glyph, one line into ~/.zshrc. glyph update fetches the latest.

Was Glyph Code

Glyph Rig was called Glyph Code until October 2026. Same tool, same glyph command, same repo: nothing to reinstall.

Nothing phoned home
