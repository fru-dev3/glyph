Glyph Rig vs Conductor

Conductor is a Mac app that runs coding agents in parallel, each in its own workspace and branch. Glyph Rig is a command-line tool that names and launches agent sessions in terminal panes, on this Mac and on your other Macs over SSH.

The short version

  • Conductor is a Mac app with an account. Glyph Rig is a zsh tool with none.
  • Conductor works on one Mac. Glyph Rig reaches sessions on your other Macs over SSH.
  • Conductor sends app analytics. Glyph Rig makes no network requests except update.

When to pick Conductor

Pick Conductor for a polished app with a built-in diff viewer, checks, isolated workspaces per agent, and iPhone remote control.

When to pick Glyph Rig

You run several command-line agents across more than one Mac and want each session named and easy to find.
