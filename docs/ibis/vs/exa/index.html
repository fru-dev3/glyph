Glyph Ibis vs Exa

Exa is a paid web search API for AI apps that returns ranked pages and their text. Glyph Ibis gives agents curated, current datasets on AI, data and tech through llms.txt, MCP and OpenAPI, free to read.

The short version

  • Exa searches the whole web on request; Glyph Ibis keeps 50+ curated sources current.
  • Exa needs an account and API key; Glyph Ibis needs none to read.
  • Both offer an MCP server for agents.
