Glyph Fleet: open agents together

Open a saved group in one command. Each agent gets its own named pane or tab.

Claudepane 1 · ci · your project
AGYpane 2 · ci · your project
Codexpane 3 · ci · your project

1. Create a fleet once

Run once to create the default fleets.

Create your fleets
glyph fleet init

Creates ci, review, and cloud in your local config.

View or customize the config

Saved to ~/.config/glyph/fleet.conf, or your GLYPH_FLEET_CONF override. Left of = is the fleet name; right is one agent per pane.

ci = claude agy codex
review = claude codex
cloud = claude:studio codex:studio

Replace studio with your SSH host before using the cloud example. AGY uses the command agy.

2. Preview the launch

Preview the group without launching anything.

Preview the ci fleet
GLYPH_DRYRUN=1 glyph fleet ci

3. Open the fleet

Open one named pane or tab per agent in your current workspace.

Start the ci fleet
glyph fleet ci

Use glyph presets to list fleets. Choose a workspace with GLYPH_FLEET_BACKEND.

Run agents on another machine

claude:studio means Claude on the SSH host studio. Replace it with a host you can already reach using SSH.

Install Glyph and the agent on that machine, source Glyph in its zsh config, and keep the project at the same path. Then run glyph fleet cloud.

The agent's mark uses that machine's own tag. Glyph's pane border also shows the SSH host so you can tell remote panes apart.

Make it yours

The defaults work without a config. Open a section when you want to change something.

Change your machine or project name

Every mark is lowercase. Hyphens join words inside a field; · separates fields: checkout-fix·acme-api·claude-code·mbp·2026-09-12·0648.

Glyph detects Mac model, WSL/Windows, Ubuntu, and generic Linux. It cannot know a Windows release or tablet model reliably, so set one explicitly: export GLYPH_MACHINE=windows-10.

For a project override, add a line to ~/.config/glyph/names.tsv: the folder name, a tab, then the name. It is normalized to lowercase hyphenated form.

Adjust naming and launch options
GLYPH_OFF=1
Keep the label and project; omit machine and time.
GLYPH_SEP
Change the separator between name parts. Default: ·
GLYPH_FMT
Set the date format. Default: %Y-%m-%d·%H%M
GLYPH_RC=0
Skip Claude's Remote Control flag.
GLYPH_TITLE=0
Leave terminal and tmux window titles unchanged.
GLYPH_LOG=0
Skip the local session log.
GLYPH_DRYRUN=1
Preview the command instead of launching an agent.
GLYPH_YOLO=1
Enable the agent's auto-approve flag. Off by default.
How Glyph fits your workflow

The wrapper builds the mark before launching the agent. For Claude, it passes -n for the session name and --remote-control for the phone bridge.

Print-mode runs and recognized subcommands, such as claude --print and codex resume, pass through.

Herdr is the recommended outer workspace: launch agents inside existing Herdr tabs and Glyph labels them. glyph fleet currently creates a standalone tmux session, so running it inside Herdr nests tmux. Use Fleet outside Herdr until a native Herdr Fleet backend exists.
