Agents in.
Named sessions out.

A zsh wrapper for Claude Code, Codex, Gemini, Antigravity and five more. It stamps your label, the project, the machine and the time onto every session before the process starts, so tmux windows, the web app and your phone all read at a glance. No daemon, no plugin, one file.

Meaning

Why

The change
One assistant in one terminal needed no name. Now agents run in parallel, on machines you are not sitting at, and ask permission on your phone.
Without it
rivers-macbook-pro-4-local-transient, agent-5e, doc-9b, zsh, node. Two of those are the same repo and you cannot tell which.
With it
billing·Acme API·laptop·0556. Label, project, machine, time — on every agent, on every machine.
By hand
You can rename a Claude session with /rename or long-press it in the app. glyph's only claim is that it happens at launch, every time, with nothing to remember.

Install

Clone
$ git clone https://github.com/fru-dev3/glyph.git
Install
$ cd glyph && ./install.sh && exec zsh
Verify
$ GLYPH_DRYRUN=1 claude billing

Copies one file to ~/.config/glyph/ and adds one line to ~/.zshrc.

Use

$ claude billing → billing·Acme API·laptop·0648

Auto-approve

Fleet

Notes

Machine tag
From hostname -s: Macs by model, everything else by the first word — DESKTOP-8KQ2LM1 → desktop, hetzner-cx41 → hetzner. Override with GLYPH_MACHINE.
Project
The git repo directory, title-cased. Override in ~/.config/glyph/names.tsv.
Untouched
-p, --print and subcommands like codex resume pass straight through, so scripts and CI are unaffected.
Knobs
GLYPH_OFF GLYPH_FMT GLYPH_SEP GLYPH_RC GLYPH_TITLE GLYPH_LOG GLYPH_DRYRUN
Why a wrapper
A name must exist before the process starts, so it can only come from argv — plugins and SessionStart hooks run too late. Claude's --remote-control <name> opens the bridge but does not name the session; only -n does, so glyph passes both.
Scope
An identity layer, not a multiplexer. Pairs with workmux, herdr or plain tmux.
