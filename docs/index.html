How it works

Keep typing the command you already type.

One bare word is your label. Anything with a space is a prompt.

1

Install once

One file, one line in .zshrc.

./install.sh && exec zsh
2

Run an agent

Add a label. The rest is filled in.

claude checkout-fix

tmux, Herdr, the web app, your phone.

Fleets

Open the whole bench with one command.

Eleven presets ship with Glyph. Every pane wears the mark.

# ~/.config/glyph/fleet.conf
review = claude codex
ci     = claude agy codex
cloud  = claude:mini codex:mini

$ glyph fleet ci

Install

zsh, MIT, one file. No daemon.

One file in ~/.config/glyph/, one line in .zshrc.

git clone https://github.com/fru-dev3/glyph.git
cd glyph && ./install.sh && exec zsh

# check it without launching anything
GLYPH_DRYRUN=1 claude checkout-fix

glyph fleet ciLaunch a fleet
glyph updateGet the latest version

Settings

GLYPH_YOLO=1Auto-approve, per-agent flag
GLYPH_DRYRUN=1Print the argv, launch nothing
GLYPH_MACHINE=laptopOverride the machine tag
GLYPH_OFF=1Label only, no machine or time
GLYPH_SEP=-Change the separator
GLYPH_FMT=%H%MChange the timestamp
GLYPH_RC=0Skip Remote Control
GLYPH_TITLE=0Leave titles alone
