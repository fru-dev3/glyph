Projects are the git repo's directory, title-cased; override in ~/.config/glyph/names.tsv. -p/--print and subcommands like codex resume pass through untouched.

Why a shell wrapper and not a plugin

A session name must exist before the process starts, so it can only come from argv. Plugins and SessionStart hooks run after that.

  • Claude Code's --remote-control <name> opens the bridge but does not name the session — only -n does. glyph passes both.
  • In zsh, argv is $@. Declaring local -a argv silently empties the positional parameters.

An identity layer, not a multiplexer. Pair it with workmux, herdr or plain tmux.
