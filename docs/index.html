Install

One file into ~/.config/glyph/, one line into ~/.zshrc. zsh, and at least one agent CLI.

~
$ git clone https://github.com/fru-dev3/glyph.git
$ cd glyph && ./install.sh && exec zsh

Keep typing what you already type

One bare word is your label. Anything with a space is a prompt. That rule is the same for every agent.

Claude Code

The one agent that can name its own session, so the mark becomes the real session name and rides Remote Control to your phone.

claude
$ claude billing
launches  claude -n 'billing·Acme API·mbp·2026-09-12·0648' --remote-control

$ claude billing "fix the webhook retry"
launches  claude -n 'billing·…' --remote-control 'fix the webhook retry'

Or open the whole bench

A preset launches several agents at once, local or over ssh, each pane wearing the mark on its border.

Claude Code · ci·Acme API·mbp
Antigravity · ci·Acme API·mbp
Codex · ci·Acme API·mbp
~/.config/glyph/fleet.conf
ci      = claude agy codex
review  = claude claude:studio
cloud   = claude:hetzner codex:hetzner

$ glyph fleet ci
  • A slot is <agent> or <agent>:<ssh-host>.
  • The part after : is an ssh host, not the machine tag.
  • Remote panes cd to the same path, and fall back to a login shell.

Projects are the git repo's directory, title-cased (acme-api → Acme API); override in ~/.config/glyph/names.tsv. -p/--print and subcommands like codex resume pass through untouched.

Why a shell wrapper and not a plugin

A session name must exist before the process starts, so it can only come from argv. Plugins and SessionStart hooks run after that.

  • Claude Code's --remote-control <name> opens the bridge but does not name the session — only -n does. glyph passes both.
  • In zsh, argv is $@. Declaring local -a argv silently empties the positional parameters.

glyph is an identity layer, not a multiplexer. Pair it with workmux, herdr or plain tmux.
