Everything Glyph does

Named at launch

Keep typing claude, codex or agy. One bare word is your label; Glyph builds the session name and hands it to the agent before the first token. Anything with a space is still your prompt.

Six tokens

Label, project, agent, machine, date and time, lowercase and joined by a dot: billing·acme-api·claude-code·laptop·0556.

Every agent

Claude Code, Codex, AGY, Cursor, Crush, Cortex, OpenCode and pi, and any other CLI you add in one line.

Every machine

The machine is part of the name, so a pane on your laptop never reads the same as one running over SSH.

On your phone

Claude sessions carry the name through Remote Control, so the list on claude.ai/code and the app reads the same as your terminal.

Fleets

One preset opens several agents at once, each in its own named pane: glyph fleet review puts two vendors on the same diff. Slots can run on another machine over SSH.

Usage and wake

glyph usage shows quota and token counts across agents. glyph wake continues Claude sessions a usage limit stopped, when the limit resets.

Spaces

Write down once which workspaces and tabs a machine opens and which agent runs in each; glyph spaces rebuilds them in Herdr after a restart.

Works where you work

zsh, with tmux, Herdr, Zellij, WezTerm or a bare shell. There is a Herdr plugin too.

Install and update

git clone https://github.com/fru-dev3/glyph.git && cd glyph && source ./install.sh. One file into ~/.config/glyph, one line into ~/.zshrc. glyph update fetches the latest.

Nothing phoned home

Glyph makes no network requests except glyph update, glyph usage --live and the GitHub star you agree to. MIT licensed.
