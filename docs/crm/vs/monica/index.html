Glyph CRM vs Monica

Monica is an open source personal CRM that runs in a browser, on your own server or on its paid hosted service. Glyph CRM is a native Mac and iPhone app that keeps people as plain notes in your own vault, with notes by voice.

The short version

  • Monica is free to self-host and $9 a month hosted; Glyph CRM is free.
  • Monica runs in a browser; Glyph CRM is a native Mac and iPhone app.
  • Monica's source is open (AGPL-3.0); Glyph CRM's is private.

Pick Monica if you want open source code you can read and change, and you are happy to run your own server.

When to pick Glyph CRM
